

# HallGuard

IoT and AI-based hallway railing hazard detection system with dual camera monitoring.

# How it works
Detects unsafe behavior based on trained model and custom dataset. When an unsafe behavior is detected, the system will send alerts through local alarm via configured audio device and sends mobile notification. The app displays the monitoring status as well as the alerts history.

# What it detects
1. Climbing on railings.
2. Sitting near railings.
3. Standing on chairs near railings.

# Development Pipeline
1. System design planning
2. Hardware setup (Raspberry Pi 5, 2 Raspberry Pi Camera Module 3, Audio Output Device)
3. Build edge device software (Python, CV, YOLOv8n)
4. Develop mobile application (Flutter)
5. System integration
6. Dataset collection
7. Model training
8. Model integration
9. Testing
10. Optimization
11. Evaluation
